Climate simulator - lightweight replacement
===========================================

Install location in the teaching website:

    teaching/climatesim/

The folder is self-contained and no longer requires the old local MathJax,
jQuery, jQuery UI, Touch Punch or Snap.svg libraries.

The numerical energy-balance calculation is based on the original simulator.
The interface has been rebuilt with native HTML range controls and a lightweight
SVG/CSS schematic. This avoids the old animation timers and responsive-layout
problems.

To replace the old version, keep a backup and replace the existing
teaching/climatesim directory with this folder.
