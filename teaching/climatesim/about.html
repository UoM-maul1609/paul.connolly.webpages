This teaching tool illustrates the effects of CH4, CO2, cloud fraction and cloud albedo in a simple representation of Earth's radiation balance.

The original simulator was produced by the Faculty of Engineering and Physical Sciences eLearning team in collaboration with the Centre for Atmospheric Science at the University of Manchester. The interface has subsequently been simplified so that it uses standard browser features and works without the older jQuery UI and Snap.svg libraries.

The underlying energy-balance calculation is intentionally compact. Students should use it to explore relationships and assumptions, and then read the model limitations before interpreting the results.

Using the simulator

  1. Press Reset to return to the reference state.
  2. Change one slider at a time.
  3. Record the direction and size of the temperature response.
  4. Explain the response using planetary albedo or infrared optical depth.
  5. Try combined changes only after you understand the individual effects.
