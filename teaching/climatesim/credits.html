The original climate simulation tool was designed, built and implemented at the University of Manchester by:

  • Stuart Anderson — web programming and interface design.
  • Paul Connolly — initial concept and prototype design.
  • David Topping — initial concept.

The current lightweight interface retains the original model calculation and selected original graphics.

Original graphic sources

  • Cow: clipartsfree.net, “chewing cow” vector.
  • Cloud: OpenClipArt cloud graphic.
  • Power station: conventional power-station clip art.

These source notes are retained from the original project so that the provenance of the teaching graphics is not lost.
