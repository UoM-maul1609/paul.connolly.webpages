Changes from the original climate simulator
===========================================

- Removed jQuery 1.x/2.x, jQuery UI, Touch Punch and Snap.svg dependencies.
- Removed recurring cow and power-station animation timers that could continue
  after graphical objects had been removed.
- Replaced custom jQuery sliders with native keyboard/touch-friendly range inputs.
- Rebuilt the layout to work reliably on desktop, tablet and phone widths.
- Preserved the original simplified energy-balance calculation and reference inputs.
- Added effective temperature, planetary albedo and infrared optical-depth outputs.
- Added a reset button and explanatory feedback relative to the reference state.
- Clarified that cloud affects short-wave reflection only in this model.
- Added an explicit limitations section and warnings for extreme slider states.
- Removed the obsolete Internet Explorer warning and Dreamweaver template machinery.
- Reduced the folder to the HTML/CSS/JS and graphics actually required.
